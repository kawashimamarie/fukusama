# 05 セルフレビューと改善結果

確認方法：ローカルサーバーで実際にブラウザ表示（Chromium / Playwright）。PC 1440×900、スマートフォン 390×844（2倍解像度）でスクリーンショットを撮り、比較・修正を繰り返した。アクセシビリティは axe-core 4.10.2、表示速度等は Lighthouse 12.2.1（モバイル設定）。

## 1. 改善の経過（見つけた問題 → 対応）

| 回 | 見つかった問題 | 対応 |
|---|---|---|
| 1 | ヒーローの写真がずれる（`figure` の既定余白） | `figure { margin:0 }` |
| 1 | PCの見出しが「おいし／さを、」のように語の途中で折り返す | 文字サイズ調整、行ごとに改行禁止 |
| 1 | スマートフォンでヘッダーの「弁当製造・卸販売」「メニュー」が2行に崩れる | 改行禁止、400px以下はメニュー文字を視覚的に隠す（読み上げは残す） |
| 2 | 「1,500食以上」の「以上」だけが次の行に落ちる | 数字と単位をひとまとまりにし、数字サイズを調整 |
| 2 | 問い合わせ帯の装飾線が見出しの上を横切る | 線画を右端の空き領域に移動、1100px以下では非表示 |
| 2 | 印章の透かしが桃色の四角として表示される（元画像の背景色） | 透かしを削除 |
| 2 | 特徴の見出し「取り組/み」が1文字だけ改行 | 見出しを「まとまった数量の製造実績」に変更。全見出しに文節単位の改行（`word-break: auto-phrase`）を適用 |
| 3 | 卸ページの目次ボックスが縦に間延び | 目次専用の詰めたスタイル |
| 3 | フォームの区切り線と「ご相談の内容」が重なる | 見出しの下線として描き直し |
| 3 | 製造ページの見出し「〜キッチンで／の製造」 | 改行位置を指定 |
| 4 | axe：注記文字のコントラスト不足、赤いマスの小文字のコントラスト不足、画面下ボタンが領域外、補足領域の入れ子 | 文字色を濃く、赤地の文字を白に、領域ラベル付与、`aside` を `div` に |
| 5 | Lighthouse 性能 68：Google Fonts のCSSが描画を止めてFCP 4.8秒 | フォントを非同期読み込みに変更、CSSを公開時に圧縮、写真に `srcset`、ロゴリンクの読み上げ名を表示文字と一致 → 性能 98 |
| — | 「多いときには**1日に**1,500食以上」と書いていた | 確認済みの事実は「製造数が多いときに1,500食以上」で「1日」とは限らないため削除 |

## 2. 最終確認結果

| 項目 | 結果 |
|---|---|
| 横スクロール（全ページ・PC/SP） | なし |
| JavaScriptエラー | なし |
| 内部リンク切れ | なし |
| axe（WCAG 2 A/AA＋ベストプラクティス、全7ページ×PC/SP） | 違反 0 |
| Lighthouse モバイル（TOP） | 性能98／アクセシビリティ100／ベストプラクティス100／SEO100、LCP 2.3秒、CLS 0.001、TBT 0ms |
| Lighthouse モバイル（卸ページ） | 100／100／100／100、LCP 1.4秒 |
| スマートフォンメニュー | 開閉、Escで閉じてボタンにフォーカスが戻る |
| スクロール表示演出 | 動きONで全18要素が表示される／動き軽減設定では最初から表示 |
| フォーム送信処理（PHP 構文・動作） | 未入力・不正メール・ヘッダー挿入の拒否、送信元チェック（403）、ボット対策、連続送信制限（429）、正常時に完了ページへ移動・メール本文の文字化けなし（いずれもローカルの擬似メール送信で確認） |

### 確認できていないこと
- **本番サーバーでの表示・フォームからの実際のメール送信**（公開前のため未実施）
- Safari / iPhone 実機、Android 実機での表示（Chromium の端末エミュレーションのみ）。文節単位の改行は Safari 非対応のため、Safari では通常の改行になる
- 本番の表示速度（ローカル計測のみ）

## 3. 評価観点ごとの自己評価

| # | 観点 | 評価 | コメント |
|---|---|---|---|
| 1 | ファーストビューで弁当製造・卸と分かるか | ○ | 見出し上のラベル「弁当製造／法人向け卸販売／大口注文のご相談」、実物写真、実績3マス、CTA「法人向け卸販売について」 |
| 2 | 法人担当者が取引を検討したくなるか | ○〜△ | 創業・実績・継続取引中・相談の流れは明確。**対応地域・価格帯・納品方法が書けていない点が最大の弱み**（未確認のため）。確定次第の追記で大きく改善する |
| 3 | 製造実績・強みが伝わるか | ○ | 1,500食以上を大きく、ただし注記つきで掲載。レストラン由来の調理経験を一貫して訴求 |
| 4 | 問い合わせまで迷わないか | ○ | 全ページのヘッダーCTA、SPの下部固定ボタン、ページ末尾のCTA帯。フォームは必須5項目＋同意のみ、未定項目は空欄可と明記 |
| 5 | 写真・文章・余白のバランス | △ | レイアウト・余白・書体は整っている。**実物写真が1枚しかなく、同じ写真が3回出る**のが品質上の最大の課題。撮影で解決する |
| 6 | PC・スマートフォンで美しいか | ○ | 両方でスクリーンショット確認済み |
| 7 | デザインの統一感 | ○ | 「仕切り」のモチーフ、色・書体・角丸・ボタンを全ページで統一 |
| 8 | SEO・アクセシビリティ・表示速度 | ○ | 上表のとおり |
| 9 | 事業内容と矛盾しないか | ○ | 未確認の条件・地域・商品名・衛生設備は記載していない。ただし福記美食の店舗サイトとの矛盾は残る（未確認事項 No.1） |
| 10 | 競合と比べた魅力 | △ | 競合（石川弁当・マコト等）は配送地域・日替わりメニュー・カロリー・試食案内などの具体情報が強い。こちらは「中華料理店の調理経験」「1995年創業」「1,500食以上」で差別化できるが、具体情報で劣る。写真と条件の追加が必要 |

Awwwards / Webby / FWA 水準について：構成・タイポグラフィ・アクセシビリティ・速度は高い水準にあるが、これらの賞は写真・映像の独自性の比重が大きく、**現状の素材（写真1枚）では受賞水準とは言えない**。撮影素材が揃えば、ヒーローの「弁当容器」グリッドに複数の写真を入れて切り替える構成にそのまま拡張できる。
