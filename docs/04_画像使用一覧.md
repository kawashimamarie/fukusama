### 表示上のルール（すべてのページで実施）
- 料理写真を並べた箇所には、必ず「写真：中華料理店『海老専家』でお出ししている料理です（弁当の内容とは異なります）」と注記している。**販売中の弁当として紹介しているのは、実物の弁当写真1点のみ**
- 製造体制ページでは「製造現場・弁当の内容とは異なります」と明記（厨房・製造現場の写真は無いため）
- 料理写真は3:2、弁当写真は4:3に統一。元画像の比率に近いため不自然なトリミングは無い
- すべて WebP、`srcset`＋`sizes` で画面幅に合った大きさを配信、`width`/`height` 指定でレイアウトのずれ（CLS）を防止。画面外の写真は遅延読み込み
- **AI生成画像は使用していない**

### 同じ写真の繰り返し
- 弁当写真：実物が1枚しかないため、4か所で使用（前回と同数。各ページの目的上、外せない）
- 料理写真6点：各2か所以内。同じページ内での重複は無い

## 4. 撮影をおすすめするもの（完成度への影響が最も大きい）
1. 弁当の商品写真（取り扱いの種類ごと・真上と斜め45度・自然光）→ 弁当紹介を商品カードの一覧にできる
2. セントラルキッチンの調理・盛り付け風景 → 製造体制ページの説得力が大きく上がる
3. まとまった数量が並ぶ様子、積み込み・納品風景 → 「1,500食以上」の裏付け
4. ヒーロー用の横長写真（1920px以上）
