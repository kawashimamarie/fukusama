# 06 公開手順書

**本番公開・FTPアップロードは、ご許可をいただくまで実施しません。** DNS・サーバー設定は変更していません。

## 0. 公開前に決めること（必須）
- 未確認事項一覧の **No.1〜No.3、No.7、No.8** に回答をいただく（福記美食の店舗サイトの扱い、問い合わせ受信先、電話番号の掲載可否、プライバシーポリシーの確認、送信元アドレス）

## 1. 現在のサーバー状況（2026-10-10 確認）
- fukushin-e.co.jp と ebisenka.jp は同じサーバー（157.120.209.50、ネームサーバー ns-rs1/ns-rs2.gmoserver.jp）
- ebisenka.jp は https が有効で、公開フォルダが空（403）
- fukushin-e.co.jp では PHP が動作している（既存の mail.php が存在）

## 2. 作業前のバックアップ
1. FTP（またはサーバー管理画面のファイルマネージャー）でコーポレートサイトの公開フォルダ全体をダウンロードして保管
2. ebisenka.jp の公開フォルダに既存ファイルがあれば同様に保管

## 3. 弁当事業サイト（ebisenka.jp）
1. フォームの設定を確認：`bento-site/src/static/contact/config.php`
   - `to`：受信先メールアドレス（現在は仮に info@fukushin-e.co.jp）
   - `from`：送信元。ebisenka.jp のメールアドレス（例 noreply@ebisenka.jp）を推奨。サーバー側でそのアドレスまたはドメインのSPFが有効か確認（無効だと迷惑メール扱いになりやすい）
   - `auto_reply`：入力者への受付確認メールを送る場合は `true`
   - `test_mode`：**本番は必ず `false`**（`true` だとメールが送信されない。プレビュー専用）
   - `base_path`：本番は空文字 `''` のまま
2. 変更したら `cd bento-site && python3 build.py`
3. `bento-site/dist/` の**中身**（`dist` フォルダごとではなく中のファイル・フォルダすべて）を ebisenka.jp の公開フォルダにアップロード
   - 隠しファイル `.htaccess` も含める（FTPソフトで隠しファイル表示をONに）
   - `.htaccess` は Apache 系の設定。サーバーが .htaccess に対応していない場合は無視されるだけで、表示には影響しない（404ページの指定・www なし統一・キャッシュ設定が効かないのみ）
4. 確認
   - https://ebisenka.jp/ ／ /wholesale/ ／ /bento/ ／ /kitchen/ ／ /about/ ／ /contact/ ／ /privacy/ が表示される
   - 存在しないURL（例 /test）で404ページ
   - https://ebisenka.jp/contact/config.php が表示されない（403 など）
   - **フォームからテスト送信**し、受信先に届くこと、完了ページに移ること、本文が文字化けしないことを確認
   - スマートフォン実機（iPhone / Android）で表示確認
   - PageSpeed Insights（https://pagespeed.web.dev/）で計測
5. Google Search Console に登録し、`https://ebisenka.jp/sitemap.xml` を送信

## 4. コーポレートサイト（fukushin-e.co.jp）
アップロードするのは次の5ファイルのみ（ほかは変更なし）：

| リポジトリ内 | サーバー上 |
|---|---|
| `corporate/index.html` | `/index.html` |
| `corporate/business.html` | `/business.html` |
| `corporate/restaurant.html` | `/restaurant.html` |
| `corporate/contact.html` | `/contact.html` |
| `corporate/assets/css/style.css` | `/assets/css/style.css` |

- `mail.php` はリポジトリに無いため、**上書きしないこと**
- 推奨順序：ebisenka.jp を先に公開 → コーポレートを更新（リンク先が空の時間を作らないため）
- 確認：トップ・事業紹介・中華レストラン経営ページの表示、「弁当事業の詳細を見る」リンクで ebisenka.jp が開くこと。CSSが古いまま表示される場合はブラウザのキャッシュを削除

## 5. 元に戻す方法
- コーポレート：手順2で保存したファイルを再アップロード
- ebisenka.jp：アップロードしたファイルを削除（元の空の状態＝403に戻る）
