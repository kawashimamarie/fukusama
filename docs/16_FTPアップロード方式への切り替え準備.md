# 16 FTP アップロード方式への切り替え準備（2026-10-10）

> **2026-10-12 更新：この準備は `17_自動公開システム.md` で実装した。** 認証情報は Claude Code の環境変数ではなく、非公開のデプロイ専用リポジトリ（fukushin-deploy）の Secrets に置く方式に変更（Claude Code からは届かない）。


**前提：Nexus サイトでの FTP 検証結果が出るまで、この方式は使わない。使える場合も、ご依頼者様が公開を明示的に承認するまで、本番サーバーには一切書き込まない（読み取り・ダウンロードのみ）。**

## 1. 認証情報（FTP 情報）の受け渡し方法
| 方法 | 内容 |
|---|---|
| 渡し方 | Claude Code のクラウド環境の設定画面（セッション上部の環境メニュー →「Edit」）で、**環境変数**（「Network secrets」欄がある場合はそちら）として登録していただく。新しいセッションから読み込まれる |
| 変数名 | `ONAMAE_FTP_HOST`／`ONAMAE_FTP_USER`／`ONAMAE_FTP_PASS` |
| 使わない経路 | チャット本文、GitHub（コード・コミット・PR・Issue）、ログ、資料、スクリーンショット |
| 取り扱い | プログラムは環境変数から読むだけで、画面・ログ・ファイルに出力しない。接続は暗号化（FTPS）を優先 |
| 推奨 | 可能であれば、今回の作業用に**対象フォルダだけに制限した FTP アカウント**を別に作り、作業後に削除またはパスワード変更（お名前.com で追加アカウントの作成・フォルダ制限ができるかは要確認） |
| 通信の許可 | この環境のネットワーク設定でお名前.com の FTP ホストへの接続が許可されている必要がある（Nexus 側の検証結果で判断） |
| メンテナンス | 2026/10/21 のサーバーメンテナンス対象の場合、10/22 以降はホスト名が変わる。新しいホスト名で登録し直す |

## 2. アップロード前に確定すること（すべて読み取りのみ）
各サイトごとに、承認をいただく前に次をまとめてご提示する。

| # | 作業 | 内容 |
|---|---|---|
| 1 | サーバーの現状を取得 | 対象フォルダのファイル一覧（パス・サイズ・更新日時）を取得 |
| 2 | バックアップ | 対象フォルダを丸ごとダウンロードし、作業環境内（Git 管理外）に保存。あわせてお名前.com の自動バックアップ（前日分）の存在を確認 |
| 3 | 差分の確定 | 最新の本番ファイル（`release/` の zip）とサーバーを比較し、**新規追加／上書き／触れないファイル**の一覧を作る。コーポレートは、上書き対象5点がサーバー上で取り込み時点（a6ba69e）と同一であることをハッシュで確認（違えば作業を止めてご相談） |
| 4 | 変更対象の確定 | ebisenka.jp：新規43ファイル／福記美食：新規31ファイル＋`.htaccess` 先頭への追記（WordPress のファイル・データベース・`wp-content` には触れない）／コーポレート：上書き5点＋新規1点（`mail.php` ほか他のファイルには触れない） |
| 5 | 復元方法の確定 | 追加したファイルの削除、上書き・変更したファイルをバックアップから戻す手順を、ファイル名単位で記載 |

## 3. アップロード（承認後のみ）
- 順番：ebisenka.jp → 福記美食 → コーポレート。1サイトずつ、前のサイトの確認が終わってから次へ
- 福記美食は、`index.html` 以外 → `.htaccess` 追記 → `index.html` の順（`15` と同じ。最後の1ファイルで切り替わる）
- 各サイトの後に、お客様にサーバーキャッシュの削除をお願いする（コントロールパネルの操作のため）

## 4. アップロード後の検証（外部から自動で確認）
- サーバー上のファイルのサイズ・ハッシュが本番ファイルと一致すること
- 全ページが 200、旧URL（福記美食11件）が 301 で正しい転送先、`config.php` が中身を表示しない、http→https・www なしへの転送
- 公開ページの内容が本番ファイルと一致（キャッシュが残っていないこと）
- 福記美食の `/wp-admin/` が残っていること、コーポレートのフォームが従来どおり動くこと
- 異常があれば、その場でバックアップから復元して報告

## 5. 記録に残すこと・残さないこと
- 残す：作業日時、対象ファイル一覧、ハッシュ、検証結果
- 残さない：ホスト名以外の FTP 情報（ユーザー名・パスワード）。バックアップの中身も Git には入れない
