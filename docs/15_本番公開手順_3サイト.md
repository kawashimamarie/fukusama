## 3. 事前確認（書き込みなし）
- [ ] お名前.com の「2026/10/21 サーバーメンテナンス」の対象案内メールが来ていないか。対象なら **10/21 当日は作業しない**。10/22 以降に FTP ソフトを使う場合は新しいホスト名に設定を直す（ファイルマネージャーなら影響なし）
- [ ] コントロールパネル「サーバー」→「自動バックアップ」で、**前日分のバックアップがあること**を確認（Web・メール・データベースを1日1回、14日分自動保存。[公式ガイド](https://www.onamae-server.com/guide/rs/p/62)）
- [ ] `python3 preview/check_live.py` で、公開中のコーポレートが取り込み時点から変わっていないこと（変わっていれば作業を止めて連絡）

## 5. 福記美食の切り替え（WordPress は削除・変更しない）

### 考え方
WordPress のファイルとデータベースはそのまま残し、新しいページのファイルを**同じフォルダに追加**して表示を切り替える。WordPress の転送設定は「実在するファイル・フォルダはそのまま表示する」作りのため、追加したページが優先して表示される。トップページは `.htaccess` の追記で `index.html` を優先させる。元に戻すときは追加分を外すだけ。
（ローカルの Apache で、WordPress と同じ転送設定を使って切り替え・旧URL転送・元に戻す動作を検証済み）

### バックアップ
1. 自動バックアップ（前日分）があることを確認（3. 事前確認）
2. ファイルマネージャーで、福記美食フォルダの **`.htaccess` をダウンロード**して保管（切り替えで唯一書き換えるファイル）
3. 可能であれば、福記美食フォルダ全体もダウンロードして保管
4. リポジトリの `fukuki-site/live-backup-20261010/` に、公開中ページの HTML と画像の控えあり（PHP・データベースは含まない）

### 切り替え手順
| 手順 | 操作 | この時点の表示 |
|---|---|---|
| 1 | フォルダ内に、新しいページと同じ名前（`bento` `kitchen` `wholesale` `access` `contact` `assets` `index.html` `404.html` `robots.txt` `sitemap.xml`）のファイル・フォルダが**既に無いこと**を確認。あれば作業を止めて連絡 | 旧サイト |
| 2 | zip の中身のうち **`index.html` 以外**をすべてアップロード | トップは旧サイトのまま。`/bento/` などの新しいURLと `/contact/` は新ページになる |
| 3 | コントロールパネルの .htaccess 編集（またはファイルマネージャー）で、既存の `.htaccess` の**先頭**（`# BEGIN WordPress` より上）に `2_ebisenka-seavans.com-htaccess-追記.txt` の内容を貼り付けて保存 | トップは旧サイトのまま。旧URL（/party/ など）は転送が始まる |
| 4 | **`index.html` をアップロード** | **ここでトップが新しいデザインに切り替わる** |

### 切り替え後の確認
- [ ] https://ebisenka-seavans.com/ が新しいトップ（「毎日のお弁当を、この厨房から。」）
- [ ] /bento/ /kitchen/ /wholesale/ /access/ /contact/ が表示される
- [ ] 旧URL：/lunch/ /food/ → /bento/、/commitment/ → /kitchen/、/info/ → /access/、/party/ /drink/ /campaign/ /news/ /sitemap/ /privacy/ → トップ
- [ ] WordPress の管理画面（/wp-admin/）にログインできる（残っていること）
- [ ] スマートフォンで表示（キャッシュが残る場合は再読み込み）

### 元に戻す（1〜2分）
1. **`index.html` を削除** → トップが旧 WordPress に戻る
2. 保管した元の `.htaccess` で上書き（または追記部分を削除）→ 旧URLの転送が止まる
3. 必要なら追加したフォルダ・ファイルを削除 → 完全に元どおり

### 既知の事項
- 新ページに無い URL（例：古い投稿）は、引き続き WordPress が表示する（旧デザイン）。不要になったら WordPress 側で非公開にする
- Google ビジネスプロフィールは変更しない（ご指示どおり）
