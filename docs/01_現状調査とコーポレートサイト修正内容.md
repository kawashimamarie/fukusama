## 2. コーポレートサイトの修正内容（`corporate/`）

変更ファイル：`index.html` / `business.html` / `restaurant.html` / `contact.html` / `assets/css/style.css`
（`company.html` `liquor.html` `food-import.html` `recruit.html` と画像・JSは変更なし）

### index.html
- title / meta description / og:title に「弁当製造」「弁当の製造・卸販売」を追加
- ヒーローのパネル：「レストラン経営 / **弁当事業** / 酒類事業 / 食品輸入卸」
- 会社紹介文に「弁当の製造・卸販売」を追加
- 事業紹介：レストランの店舗一覧から福記美食を削除。**04 弁当製造・卸販売** カードを追加（ご指定の見出し・本文の要約＋「多いときは1,500食以上を製造」「製造拠点：福記美食」、CTA「弁当事業の詳細を見る」→ ebisenka.jp）
- 事業サイト：福記美食カードと弁当事業カードを統合して「弁当事業」カード1枚に（福記美食は弁当の製造拠点のため）。CTA「弁当事業の詳細を見る」→ ebisenka.jp。**ebisenka-seavans.com へのリンクは外した**（未確認事項 No.1）
- お問い合わせ・フッターの事業一覧に「弁当事業」を追加

### business.html
- 「3つの事業領域」→「**4つの事業領域**」、弁当製造・卸販売カードを追加
- 新設ブロック（`#bento`）：ご指定の見出し「毎日の食を支える、弁当製造・卸販売。」と説明文3段落をそのまま掲載、CTA「弁当事業の詳細を見る」→ https://ebisenka.jp/
- 同ブロック内に「**福記美食｜弁当製造・販売拠点**」とご指定の説明文、「※現在は店内での飲食営業を行っていません。」

### restaurant.html
- 運営店舗から福記美食を外し（海老専家・海老専家天山店の2店舗）、その下に「福記美食｜弁当製造・販売拠点」ブロックを追加（同じ説明文と注記、ebisenka.jp へのCTA）
- 客席が写った福記美食の店内写真は、店内飲食と誤認されるため使用をやめ、実際の弁当写真に変更

### contact.html
- 冒頭の案内文に「弁当事業」を追加
- フォームの「お問い合わせ種別」は**変更していない**。送信先の `mail.php`（サーバー上にあり、ソースはこちらで確認できない）が種別の値を照合している場合、新しい選択肢を追加すると送信に失敗するおそれがあるため。→ 未確認事項 No.9

### assets/css/style.css（末尾に追記のみ）
- カード4枚・2枚に合わせた列数の調整（`business-grid--4` `content-grid--4` `site-grid--4` `content-grid--2`）、注記用の `.note-text`、`.lead-panel h3`
- 既存ルールは変更していない。PC（1440px）とスマートフォン（390px）で横スクロールが出ないことを確認済み

### 「1,500食」の表現
- 使っている表現は「多いときには1,500食以上を製造するなど」「多いときは1,500食以上を製造」のみ。「最大」「毎日」「常時」「製造能力」とは書いていない
