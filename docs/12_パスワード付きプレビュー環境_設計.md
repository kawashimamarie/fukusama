## 0. 結論（要約）
- プレビューURL案：**`https://ebisenka.jp/_preview-fk2026/`**
- 置き場所：ebisenka.jp の公開フォルダ（現在は空）の中に、プレビュー専用フォルダを1つだけ作る。**コーポレートサイト（fukushin-e.co.jp）のフォルダには何も置かない**
- 認証：Basic認証（ID・パスワード）。パスワードファイルは公開フォルダの外に置き、Git には保存しない
- 検索エンジン対策：認証（未認証は 401）＋ `X-Robots-Tag: noindex` ＋ 全ページの `noindex` メタタグ。サイトマップ・canonical は入れない
- フォーム：**メールを送らないテストモード**（送るはずの内容を画面に表示するだけで、入力内容も保存しない）。コーポレートのフォームはプレビュー専用のテスト用ページへ送る（**本番の mail.php には一切触れない**）
- 公開用ファイル一式は作成・検証済み（`python3 preview/build_package.py` で生成。78ファイル・12.4MB）
- **注意：お名前.com が 2026-10-21 に RSプランの一部サーバーの移設を予定**。対象の場合、移設前に置いたファイルは引き継がれないため、構築は対象かどうかの確認後（対象なら 10/22 以降）を推奨

## 2. ディレクトリ設計

```
（ebisenka.jp の公開フォルダ）        ← 現在は空。今回は直下にファイルを置かない
└─ _preview-fk2026/                   ← プレビュー専用フォルダ（これだけを追加）
    ├─ .htaccess                      ← Basic認証・noindex・一覧表示禁止・設定ファイル保護
    ├─ index.html                     ← 入口（両サイトへのリンク・注意書き）
    ├─ bento/                         ← 弁当事業サイト（プレビュー用に変換済み）
    │   └─ contact/config.php         ← test_mode = true（メール送信しない）
    └─ corporate/                     ← コーポレートサイト（修正版のコピー）
        └─ preview-mail.php           ← テスト用（本番 mail.php とは別名・別フォルダ）

（公開フォルダの外 ※場所はサーバー確認後に決定）
└─ .htpasswd_preview                  ← ID・パスワード（暗号化済み）。Git には保存しない
```

| 設計上のポイント | 内容 |
|---|---|
| 本番ファイルと混在させない | プレビューは `_preview-fk2026/` の中だけ。本番公開時は公開フォルダ直下に**別に作った本番用ファイル**（`bento-site/dist/`）を置き、プレビュー用は使い回さない |
| fukushin-e.co.jp を選ばない理由 | 公開中サイトのフォルダや設定（.htaccess 等）の影響を受けたり与えたりするおそれをゼロにするため |
| サブドメイン（preview.ebisenka.jp 等）を選ばない理由 | DNS と SSL の設定変更が必要になるため（今回の条件で禁止） |
| フォルダ名 | `_preview-fk2026`（変更可）。推測されにくい名前にしつつ、認証が本来の防御 |

### プレビュー用に自動で変換している内容（`preview/build_package.py`）
| 対象 | 変換内容 |
|---|---|
| 弁当サイトのリンク・画像のパス | ドメイン直下前提の `/...` を `/_preview-fk2026/bento/...` に変換 |
| サイト間リンク | `https://ebisenka.jp/` → プレビュー内の弁当サイト、`https://fukushin-e.co.jp/` → プレビュー内のコーポレート |
| 全ページ | `noindex, nofollow, noarchive` メタタグを追加、canonical を削除、画面右下に「PREVIEW｜非公開の確認用」表示 |
| 不要ファイル | sitemap.xml・robots.txt・本番用 .htaccess は含めない |
| 弁当サイトのフォーム | `test_mode => true`、`base_path => '/_preview-fk2026/bento'` |
| コーポレートのフォーム | 送信先を `mail.php` → `preview-mail.php`（テスト用。送信も保存もしない）に変更 |

本番用の `bento-site/dist/` は変換していない（本番フォームは `test_mode => false`、`base_path => ''` のまま。動作に変化がないことを再テスト済み）。

## 3. 認証方式

| 方式 | 内容 | 評価 |
|---|---|---|
| **A. .htaccess＋.htpasswd による Basic認証（推奨）** | 上記の .htaccess で `_preview-fk2026/` 以下すべてに ID・パスワードを要求。パスワードファイルは公開フォルダの外 | ローカルの Apache 2.4 で動作確認済み。設定がフォルダ内で完結し、削除も容易 |
| B. コントロールパネルの「アクセス制限」機能 | 画面操作で設定（存在・仕様は要確認） | 使える場合は手軽。**A と同じフォルダに併用しない**（第三者の解説記事で、同じフォルダへの併用はできないとされている。公式情報は未確認） |

運用ルール：
- ID・パスワードは構築時に決め、**メール本文やチャットに書かず**、電話・社内チャット等の別経路で担当者に伝える。Git・資料には書かない
- 共有範囲は福進発展のご担当者のみ。確認期間が終わったら削除（下記「8」）
- 通信は https のみ（http は自動で https に転送される）

## 7. プレビューから本番への移行手順
1. 未確認事項（受信先メール、送信元アドレス、電話番号、プライバシーポリシー等）を反映し、`python3 bento-site/build.py`
2. **本番用は `bento-site/dist/` の中身**を ebisenka.jp 公開フォルダ直下にアップロード（プレビュー用 `preview-package/` は使わない）
   - `contact/config.php` が `test_mode => false`、`base_path => ''` であることを確認
3. 本番の確認：全ページ表示、`/contact/config.php` が見えない、**フォームを架空の内容で1回だけ実送信**して受信を確認
4. コーポレートの5ファイル（index / business / restaurant / contact / style.css）をアップロード（mail.php は触らない）
5. `_preview-fk2026/` と `.htpasswd_preview` を削除（下記「8」）
6. Search Console 登録、sitemap 送信

## 8. 削除手順（確認期間終了時、または本番公開時）
1. ★ ebisenka.jp 公開フォルダから `_preview-fk2026/` を**フォルダごと**削除
2. ★ 公開フォルダの外の `.htpasswd_preview` を削除
3. 確認：`https://ebisenka.jp/_preview-fk2026/` が 404（本番公開前なら、ドメイン直下は 403 のまま）
4. ID・パスワードを伝えた担当者に、プレビュー終了を連絡
5. 手元の `preview-package/` は Git 管理外。不要なら削除
