## 自分のPCで動かして確認する（推奨）

本番と同じHTML・CSS・JavaScriptを、手元のPCで表示します。**インターネットには公開されません。** 費用もかかりません。

### 必要なもの
- **Python 3.8 以上**：Mac は標準で入っていることが多い（ターミナルで `python3 --version`）。Windows は https://www.python.org/ から入れる
- **PHP**（任意・Mac/Linux）：入っていればフォームの送信処理も本番と同じ形で試せる。無くても表示の確認はできる（Windows では常に確認画面モード）

### 手順
1. GitHub からリポジトリを取得し、ブランチ `claude/bento-business-site` に切り替える
   - GitHub の画面で「Code」→「Download ZIP」でも可（ブランチを `claude/bento-business-site` にしてから）
2. リポジトリのフォルダで次を実行
   ```
   python3 preview/serve.py
   ```
   （Windows は `py preview\serve.py`）
3. ブラウザで開く
   - 弁当事業サイト：http://localhost:8080/
   - コーポレートサイト：http://localhost:8081/
4. 終了するときはターミナルで Ctrl+C

### このプレビューでできること
| 確認項目 | 方法 |
|---|---|
| 弁当サイトの全ページ | 8080 番。ヘッダー・フッターのリンクで全ページに移動できる |
| コーポレートの修正ページ | 8081 番の「事業紹介」「中華レストラン経営」、トップの事業紹介・事業サイト欄 |
| サイト間のリンク | コーポレートの「弁当事業の詳細を見る」→ 8080 番の弁当サイトへ、弁当サイトの「コーポレートサイト」→ 8081 番へ移動する（プレビューの中で完結するよう自動で書き換えている） |
| スマートフォン表示 | Chrome / Edge で F12 →「デバイスのツールバー」（スマホの形のアイコン）→ iPhone などを選ぶ。またはウィンドウの幅を狭くする |
| 実機のスマートフォン | `python3 preview/serve.py --host 0.0.0.0` で起動し、**同じWi‑Fi**のスマートフォンから `http://（PCのIPアドレス）:8080/` を開く。社内ネットワークでのみ使うこと |
| アニメーション | ページを下にスクロール（写真・文字が順に表示される）。2回目以降は動かない仕様 |
| メニュー操作 | 画面幅を狭くすると右上にメニューボタン。開閉、Esc キーで閉じる |
| お問い合わせフォーム | 8080 番の /contact/。**PHP がある場合**は本番と同じ送信処理が動き、完了ページに進む。メールは送らず `preview/outbox/` に保存される。**PHP が無い場合**は送信ボタンで入力内容の確認画面が出る |

### 注意
- プレビューはファイルを直接表示しているだけで、サーバーの設定（`.htaccess` のリダイレクト等）は再現していない
- コーポレートサイトの読み込み画面（約1.5秒）は既存サイトの仕様（今回は変更していない）
